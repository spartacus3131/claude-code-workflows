# Elegant Redo

After a working but messy implementation, step back and redesign from scratch with everything you've learned.

## Steps

1. **Analyze what exists.** Read the current implementation. Identify the core problem it solves, the inputs/outputs, and what's messy about it.

2. **Articulate the insight.** Before rewriting, state: what the core problem is, what's wrong with the current approach, and the key realization that enables a better one.

3. **Propose the new approach.** Describe the conceptual shift, the new structure, why it's better, and any trade-offs. Show estimated line count reduction. Ask the user to confirm before proceeding.

4. **Implement cleanly.** Delete the old code. Use the language idiomatically. Handle errors as part of the design, not bolted on.
